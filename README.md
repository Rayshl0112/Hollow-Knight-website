Hollow Knight Fan Project: LE2 Asset Package
Overview
This repository contains visual assets, charms, equipment icons, and environment backgrounds inspired by Hollow Knight and Hollow Knight: Silksong. The assets are organized within the Palisoc-MariaRaychelle_#LE2/img/ directory for game engine integration or web UI components.

Workspace Directory Structure

Supported Formats & Optimization
WEBP: Used for all modular charm and nail icons to reduce load footprint while retaining alpha transparency.

PNG: Used for high-resolution character sprites, vector UI elements, and art icons.

JPEG: Used for compressed region background textures (Deepnest.png, greenpaths.png).
