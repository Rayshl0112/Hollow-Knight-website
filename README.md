# Hollow Knight Fan Site - Media Assets

This directory contains key graphic assets and imagery used across the **Hollow Knight Fan Site** project (developed by Palisoc).

## 📁 Directory Structure & File Overview

| File Name | Description | Format |
| :--- | :--- | :--- |
| `Hollow_Knight_Logo.webp` | Official game logo banner asset | WebP |
| `B_Hollow_Knight.png` | Key art graphic of Hollow Knight character | PNG |
| `Hornet_Idle.png` | Character sprite asset for Hornet (Idle pose) | PNG |
| `The_Knight_Resting.png` | Art asset featuring The Knight resting at a bench | PNG |
| `The_Hollow_Knight_Stagger.png` | Combat sprite featuring the Hollow Knight staggered | PNG |
| `Hollow-Knight-boss-fight.png` | High-resolution boss battle gameplay artwork | AVIF |
| `hollow-knight-silksong-hornet-attack-vintage-dominic-craig-transparent.png` | Vintage illustration artwork of Hornet attacking (*Silksong*) | PNG |
| `Steam_icon_logo.svg.png` | Steam platform logo icon | PNG |
| `Xbox_one_logo.svg.png` | Xbox One platform logo icon | PNG |
| `nintendo-logo-vector-format-11.png` | Nintendo Switch platform logo icon | PNG |

---

## 🎨 Asset Details & Usage

- **Characters & Gameplay Art:** Used in the fan site's hero sections, media galleries, and character lore pages.
- **Platform Badges:** Displayed in the header/footer and acquisition sections to link to official store pages (Steam, Xbox, Nintendo).

---

## 💻 Tech Stack & Compatibility

- Modern web image formats (WebP, AVIF, PNG with alpha transparency).
- Optimized for fast load times and responsive display across desktop and mobile devices.
